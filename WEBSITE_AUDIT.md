## 🔍 AUDIT RULES

### FUNCTIONALITY
- All buttons, links, and forms must work
- No console errors
- No broken routes

### RESPONSIVENESS
- No horizontal scrolling on mobile
- Proper scaling of text and images
- Navigation usable on touch devices

### PERFORMANCE
- Avoid images > 300KB unless justified
- Use modern formats (WebP/AVIF)
- Minimize JS bundles

### UI/UX
- Consistent spacing system
- Clear visual hierarchy
- CTA must be visible without confusion

### SEO
- One H1 per page
- Proper meta title & description
- Semantic HTML

### ACCESSIBILITY
- Use labels for inputs
- Ensure contrast ratio is readable
- Keyboard navigable UI

---

- Be brutally honest (no soft feedback)

- Suggest **specific code-level fixes when possible**
- If something is good → briefly explain why
